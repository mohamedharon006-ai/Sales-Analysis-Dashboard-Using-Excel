# Sales Analysis Dashboard Using Excel

## 📊 Project Overview

This project presents an interactive sales dashboard developed using Microsoft Excel to analyze sales performance and provide useful business insights.

The dashboard visualizes sales data across different customers, regions, product categories, and time periods. It enables users to explore sales trends, compare performance, and identify key contributors to overall sales.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify top-performing customers.
- Compare sales across different geographical regions.
- Analyze sales by product category and customer segment.
- Track sales trends over time.
- Enable interactive data exploration through dashboard filters.

## 📈 Dashboard Features

- **Customer Analysis:** Compare sales performance across customers.
- **Regional Analysis:** Explore sales distribution across geographical regions.
- **Product Analysis:** Analyze sales by product and category.
- **Time-Based Analysis:** Monitor sales trends across different months.
- **Interactive Filters:** Filter dashboard results by customer and region.
- **Data Visualization:** Present sales insights through interactive charts.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Data Analysis
- Data Visualization

## 💡 Key Learnings

- Building interactive dashboards in Excel.
- Analyzing sales performance using Pivot Tables.
- Visualizing trends and comparisons through charts.
- Using interactive filters to explore business data.
- Presenting data in a clear and meaningful way.
